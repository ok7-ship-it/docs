What is GKD?
GKD is an obstacle-free, high-end selector with a custom screen dot based on rules for Android applications.

Use the scene
By custom rules, click a specific node or location or perform other operations when the specified conditions are satisfied on the specified interface (such as the presence of specific text on the screen).

Quick operation

Help you simplify some repetitive processes, such as certain software automatically confirming computer login

Skip the process

Some software may have some annoying processes when starting, and this software can help you click to skip this process.
